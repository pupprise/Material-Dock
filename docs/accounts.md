# 账号与权限

`manage.py init` 创建姓名与角色映射、初始密码哈希和专属密钥哈希。初始密码由随机数生成，也可用 `--prompt-password` 在本机交互设置。各人的邀请 ZIP 和名单生成到 `private/`，管理员按名单单独分发。专属链接包含可用于找回密码的凭据。

设计师可访问本人需求、通知和对应附件，也能按名称、简称或主营物料检索供应商。材料员可访问跟单和供应商管理，代设计师提报时记录实际操作人和需求归属。联系人、电话等详细目录字段仅返回材料员。

有效会话在 SQLite 中保留令牌哈希，通常有效八小时。受信个人设备期限为三十天。换密码或恢复初始密码会使旧会话失效。生产部署使用 HTTPS，避免复用演示凭据。

`accounts.py` 管理账号和会话结构，`credentials.py` 管理密码散列，`server.py` 执行 HTTP 权限与记录范围校验。
