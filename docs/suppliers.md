# 供应商库

1. 从材料员侧栏打开「供应商库」，下载模板。主表第 1 行是表头，第 2 行起每行一家。供应商名称必填。其他字段包括简称、主营物料、联系人、电话、邮箱、地址和备注。
2. 上传最多 5 MB 的 `.xlsx`。一次处理最多 500 条。电话建议保留为文本，确保前导零不会丢失。预览可展开每行核对，重复和无效行会单独提示。
3. 勾选有效行确认。并发导致重名时，该次提交会整批回滚。可重新预览，也可用「编辑」维护已有记录。
4. 设计师录入需求或整理 Excel 预览时，可以按名称、简称和主营物料检索目录，也可以手填目录外名称。已提交需求保留本次所选名称。

`suppliers.py` 检查工作簿、规范化名称和执行目录写入，`web/supplier-ui.js` 提供目录与候选选择。
