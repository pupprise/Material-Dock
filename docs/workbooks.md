# 工作簿与文件

在「新建需求」上传 `.xlsx`，上限 100 MB，每次最多 1,000 条需求。预览按款号分组，补齐项目、用途和需求到料日并核对数量、单位。表里的「收到日期」供核对，提交时确认需求到料日。

支持 WPS DISPIMG、Excel 单元格内图像和锚定到物料行的浮动图。外链图片、找不到文件的引用和未匹配到物料行的图片会阻止导入。没有图片标记的普通物料行可以正常提交。

手传参考图支持 JPEG、PNG、WebP、GIF 和 BMP。服务按流保存原图，生成缩略图，并拒绝无法解码的文件。照片受可用磁盘、解码资源和网络条件约束。矢量图附件走独立流程，每个 20 MB，每条最多八个且合计 60 MB。

材料员导出遵循当前筛选与搜索条件。Excel 中记录参考图的存在情况，原图和附件通过工作台查看。文件处理相关模块为 `excel_import.py`、`reference_photos.py`、`workbook_export.py`。
