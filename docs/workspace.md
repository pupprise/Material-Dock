# 工作台与业务状态

- **设计师**可手动新建、粘贴单行或上传工作簿，多条 Excel 明细按一次提交组织为一轮。可按项目、厂家、日期、状态和关键词搜索；保存的常用筛选存于当前浏览器。
- **材料员**可代下单、按筛选结果勾选部分或全部可跟进记录、批量回填供应商和交期、登记多次实收并导出当前筛选。批量写入先核对所有记录版本，发现冲突会回滚该批次。
- **变更**。未登记实收的需求可修改、搁置、重新激活或撤销。已搁置或已撤销的需求可作废，档案保留异常状态和原因。
- **状态**。黄色普通，橘色加急，红色交期异常，绿色已到齐，灰色暂停或归档。交期异常优先着红色，另显示加急标签。详情显示数量、规格中的数字、参考图及时间线。

`server.py` 保存业务状态、通知、事件与写入操作编号。`web/app.js` 实现双方看板和交互。
